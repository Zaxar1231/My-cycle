# Ведение PR

- **Заголовок PR — это семантическая версия следующего релиза** (`fix:`, `feat:`, `feat!:`, `#norelease`). Меняешь только CI, документацию или `.claude/` — добавь `#norelease`.
- Вливаем merge-коммитом. Ветки агентов: `claude/...`. Если PR этой ветки уже влит, новую работу начинай заново от свежего `main` (`git checkout -B <ветка> origin/main`).
- Красный CI на своём PR чинить сразу; перед повторным push разбери лог (скил `android-ci`).
- Красный CI на `main` важнее всего, потому что из-за него краснеют все PR.
- Dependabot-PR: зелёные вливаются автоматически. Красные из-за несовместимых версий заменять одним сводным PR, а старые закрывать с комментарием.
- Сам PR не вливать: это делает пользователь. Исключение — автомерж Dependabot.
- Ответы и комментарии в PR пиши по-русски.
