# Supabase для Twilight Cycle

Аккаунты и партнёрский режим работают через ваш собственный проект [Supabase](https://supabase.com).
Бесплатного тарифа хватает. Пока проект не подключён, в приложении просто нет раздела аккаунтов:
всё остальное работает офлайн.

Что уходит на сервер:
- **Этап 9а (аккаунты):** только email и пароль (пароль хранит Supabase Auth в виде хэша).
- **Этап 9б (партнёрский режим):** только зашифрованные на телефоне данные. Ключ шифрования передаётся
  партнёру внутри QR-кода/кода приглашения и на сервер не попадает, поэтому прочитать данные сервер не может.

## 1. Создать проект

1. Зайдите на [supabase.com](https://supabase.com), войдите и нажмите **New project**.
2. Укажите имя (например, `twilight-cycle`), придумайте пароль базы данных (сохраните его у себя), выберите
   ближайший регион. Нажмите **Create new project** и подождите пару минут.

## 2. Настроить вход по email

1. **Authentication → Sign In / Providers → Email** — должно быть включено (по умолчанию так и есть).
2. **Confirm email** — по желанию:
   - включено (по умолчанию): после регистрации придёт письмо, вход — после подтверждения адреса;
   - выключено: вход сразу после регистрации.
3. Бесплатная почта Supabase отправляет лишь несколько писем в час. Для подтверждений и сброса пароля
   этого хватает на пару человек; для большего подключите свой SMTP в **Authentication → Emails → SMTP Settings**.

## 3. Передать адрес и ключ в сборку

1. В проекте Supabase откройте **Project Settings → API** (или **Connect**).
2. Скопируйте **Project URL** (вида `https://xxxx.supabase.co`) и ключ **anon public**
   (он публичный по замыслу Supabase: доступ к данным ограничивают правила RLS, а не секретность ключа).
3. В GitHub откройте репозиторий → **Settings → Secrets and variables → Actions → New repository secret**
   и создайте два секрета:
   - `SUPABASE_URL` — Project URL;
   - `SUPABASE_ANON_KEY` — anon public key.
4. Следующий релиз соберётся уже с аккаунтами. Ключ `service_role` в приложение **не добавляйте никогда**.

## 4. Таблицы для партнёрского режима

SQL-миграция с таблицами и правилами RLS появится вместе с этапом 9б и будет лежать в `docs/supabase/`.
