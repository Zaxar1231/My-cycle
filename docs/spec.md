# Промт для Claude Code: приложение-трекер менструального цикла

## Роль и задача

Ты — senior Android-разработчик. Мы с нуля пишем нативное Android-приложение для отслеживания менструального цикла с партнёрским режимом, маскотом-питомцем и кастомными темами. Работай итерациями: сначала план и каркас, потом фичи по этапам (см. раздел «Этапы»). После каждого этапа проект должен собираться и запускаться. Перед стартом каждого этапа кратко опиши, что будешь делать, и задай вопросы, если что-то неоднозначно.

Язык интерфейса — русский (строки сразу в `strings.xml`, чтобы потом добавить английский).

## Стек

- Kotlin, Jetpack Compose, Material 3 (Material You, dynamic color)
- Архитектура: Clean Architecture + MVVM, модули `:app`, `:core:ui`, `:core:data`, `:core:domain`, `:feature:*`
- DI: Hilt
- Локальная БД: Room + SQLCipher (данные о здоровье хранятся зашифрованными)
- Настройки: DataStore
- Асинхронность: Coroutines + Flow
- Навигация: Navigation Compose
- Виджеты: Jetpack Glance
- Уведомления/фоновые задачи: WorkManager
- Бэкенд для аккаунтов и партнёрской синхронизации: Supabase (Auth + Postgres + Realtime + Row Level Security). Слой сети вынеси за интерфейс, чтобы потом можно было заменить на свой self-hosted сервер
- Графики: Vico (или Canvas вручную, если Vico не справится)
- PDF-отчёт: android.graphics.pdf.PdfDocument
- Тесты: JUnit5 + Turbine для доменной логики, особенно для алгоритма прогнозов

Принцип: **local-first**. Всё работает офлайн, синхронизация с сервером — только для партнёрского режима и бэкапа, по согласию пользователя.

## Навигация (нижний бар)

По аналогии с референсом: `Календарь` · `Статистика` · **[+] (FAB по центру — быстрая запись дня)** · `Питомец` · `Настройки`.

## Функционал

### 1. Календарь и цикл (главный экран)
- Месячный календарь с полным оформлением цикла: дни месячных, фертильное окно, день овуляции, лютеиновая фаза, прогнозируемые дни — разными цветами/обводкой, с легендой
- Крупная карточка «сегодня»: **день цикла**, текущая фаза (менструальная / фолликулярная / овуляторная / лютеиновая), сколько дней до следующих месячных и до овуляции
- **Вероятность забеременеть** на сегодня (низкая / средняя / высокая + процент-оценка) с обязательной подписью, что это не метод контрацепции
- Тап по любому дню → детали дня и записи

### 2. Ежедневная запись (FAB «+»)
Bottom sheet / отдельный экран с чипами и быстрым вводом:
- Начало/конец месячных
- Обильность (мажущие / слабые / средние / обильные)
- Настроение — меню с выбором (эмодзи-иконки, можно несколько)
- Симптомы (боль внизу живота, головная боль, вздутие, акне, чувствительность груди, усталость, тяга к сладкому и т.д.)
- Сексуальная активность (была / защищённая / незащищённая)
- Базальная температура
- Вес
- Принятые медпрепараты (свой список препаратов + напоминания о приёме)
- Заметка (свободный текст)

### 3. Контент по дням и фазам
Для каждого дня цикла на основе фазы показывать:
- **Возможные симптомы** на этот день
- **Плюсы / преимущества** фазы (например, прилив энергии в фолликулярной, пик либидо и уверенности около овуляции)
- **Минусы / неудобства** фазы (ПМС, отёки, раздражительность в поздней лютеиновой и т.п.)
- **Совет дня** (питание, активность, самочувствие)
- **Анализ фаз цикла** — экран с объяснением каждой фазы и где пользователь сейчас

Контент храни в локальных JSON-файлах в `assets/` (фаза → список симптомов, плюсов, минусов, советов), чтобы его было легко редактировать без перекомпиляции логики. Тексты нейтральные, научно-популярные, без медицинских диагнозов.

### 4. Гормоны
- Экран с графиком примерных уровней гормонов по дням цикла: эстроген (эстрадиол), прогестерон, ЛГ, ФСГ, тестостерон
- Отметка «вы здесь» на текущем дне
- Короткое описание, что делает каждый гормон и как он влияет на самочувствие сейчас
- Кривые — типовые нормированные модели, масштабируемые под длину цикла пользователя. Явно подписать, что это модель, а не анализ крови

### 5. Прогнозы
- Алгоритм прогноза вынеси в отдельный чистый класс `CyclePredictor` в `:core:domain`, покрой unit-тестами
- Базовая логика: взвешенное среднее последних 6 циклов (свежие весят больше), отбрасывание выбросов (циклы < 21 или > 45 дней не учитывать в среднем, но показывать в истории)
- Овуляция ≈ длина цикла − 14 дней; фертильное окно = 5 дней до овуляции + день овуляции
- Уточнение по базальной температуре: если есть данные, детектить сдвиг температуры (+0.2–0.5 °C три дня подряд) и корректировать фактическую дату овуляции
- Показывать уверенность прогноза (чем стабильнее циклы и больше данных — тем выше)
- Если данных меньше 2 циклов — использовать значения из онбординга

### 6. Статистика (отдельная вкладка)
Вкладки как в референсе: **Циклы · Записи · Хронология**.
- Краткая сводка о последнем цикле и месячных: длительность цикла, длительность месячных, даты
- Средняя длина цикла и месячных, разброс, регулярность
- **История циклов**: список карточек «28 авг. – 25 сент.», под каждой — горизонтальная полоска из «таблеток»-дней, где цветом выделены месячные, фертильное окно и овуляция, подпись «9 дней — месячные, 29 дней — цикл». Кнопка «Редактировать» для правки прошлых циклов
- Расширенная статистика: графики длины циклов, частота симптомов, настроение по фазам, температура, вес, корреляции (например, «головная боль чаще всего на 1–2 день цикла»)

### 7. Отчёт для врача
- Генерация PDF за выбранный период: даты и длительность циклов и месячных, обильность, симптомы, настроение, температура, вес, препараты, заметки
- Аккуратная вёрстка, таблицы + пара графиков
- Поделиться через системный share sheet

### 8. Партнёрский режим
- Два типа аккаунта: **основной** (тот, кто ведёт цикл) и **партнёрский**
- Подключение: основной аккаунт генерирует код/QR-код приглашения → партнёр вводит/сканирует → связка
- Партнёр видит: день цикла, текущую фазу, прогноз месячных, настроение (если основной разрешил), **советы, как поддержать свою половинку** в эту фазу
- Основной аккаунт гранулярно управляет, что видно партнёру (тумблеры: фаза, настроение, симптомы, фертильность). Интимные данные и заметки по умолчанию скрыты
- Возможность отвязать партнёра в любой момент, данные у партнёра сразу пропадают
- В Supabase всё закрыто через RLS: партнёр читает только разрешённые поля, только по активной связке
- Пуш-уведомления партнёру («скоро начнутся месячные — будь внимательнее»), опционально

### 9. Здоровье и настроение
- **Дыхательная медитация**: анимированный круг/маскот, который «дышит» (вдох–задержка–выдох), несколько техник (4-7-8, квадратное дыхание, медленное дыхание для облегчения боли), таймер, мягкая вибрация на смену фаз
- **Генерируемые аффирмации**: аффирмация дня с учётом фазы и настроения. Первая версия — генерация из локальных шаблонов и словарей; заложи интерфейс `AffirmationGenerator`, чтобы позже подключить LLM API. Кнопка «ещё», избранное, поделиться

### 10. Питомец-маскот
- При регистрации — **одноразовый** выбор животного (котик, лисёнок, зайка, панда, пингвин и т.д.). Потом сменить нельзя — показать это явно на экране выбора с подтверждением
- Питомец появляется на главном экране и реагирует на фазу/настроение (анимации: спит, радуется, грустит, обнимает грелку во время месячных)
- Кастомизация: одежда, причёски, аксессуары
- Прокачка: за ежедневные записи, медитации, серии дней пользователь получает очки/монетки → открывает новые вещи
- **Совместное выращивание с партнёром**: если аккаунты связаны, питомец общий, партнёр тоже может заботиться о нём (кормить, дарить вещи), действия обоих синхронизируются
- Анимации — Lottie или Rive (выбери и обоснуй). Для старта сделай заглушки-плейсхолдеры, чтобы потом подставить реальные ассеты

### 11. Темы и оформление
- Material You (dynamic color из обоев) как тема по умолчанию
- Набор готовых тем + **кастомная** (выбор основного цвета, светлая/тёмная/по системе)
- Отдельный стиль **Liquid Glass** (полупрозрачные размытые карточки, `Modifier.blur`/RenderEffect на Android 12+, с fallback для старых версий) и ещё 1–2 стиля на твой выбор
- Все цвета фаз цикла берутся из темы, а не захардкожены
- **Круговая палитра** в настройках: выбор акцентного цвета на цветовом круге и яркости, из него строится вся схема Material 3 для светлой и тёмной темы
- **Вид главного экрана** на выбор: Кольцо с цветами, Луна (растёт и убывает вместе с циклом), Орбита, Волна, Мозаика. Больше воздуха: широкие отступы, крупная типографика, меньше плашек на первом экране
- **Шрифт приложения**: Системный, Inter, Nunito, Comfortaa, Lora, Caveat (OFL, вшиты в APK, без загрузки из сети) и свой шрифт из файла .ttf/.otf
- **Кастомизатор главного экрана**: перетаскивание и скрытие блоков, размер и вид плашек (заливка, контур, стекло, скругление), свой цвет каждой плашки из круговой палитры или из темы

### 12. Безопасность
- **PIN-код для входа** по желанию + разблокировка по биометрии
- Экран ввода PIN в нескольких стилях (Material You, Liquid Glass и т.д. — в соответствии с выбранной темой)
- Блокировка при сворачивании через N минут (настраивается)
- Скрывать содержимое в списке недавних приложений (FLAG_SECURE, опционально)
- Экспорт/импорт зашифрованного бэкапа

### 13. Виджеты (Glance)
- Маленький: день цикла + фаза
- Средний: дни до месячных/овуляции + мини-полоска цикла
- Виджет с питомцем
- Виджет быстрой записи настроения

### 14. Уведомления
- Скоро месячные / начало фертильного окна / овуляция
- Напоминание о записи дня
- Приём препаратов
- Всё настраивается в «Настройках»

## Онбординг
1. Приветствие
2. Регистрация / вход (или «продолжить без аккаунта» — тогда партнёрский режим недоступен)
3. Роль: «веду цикл» или «я партнёр»
4. Для основного: дата начала последних месячных, средняя длина цикла и месячных (с вариантом «не знаю»)
5. Выбор питомца (одноразовый, с подтверждением)
6. Выбор темы
7. Предложение поставить PIN

## Модель данных (минимум)
`User`, `Cycle` (startDate, endDate, periodLength, cycleLength, isPredicted), `DayLog` (date, flow, moods, symptoms, sexActivity, temperature, weight, medications, note), `Medication`, `PartnerLink` (ownerId, partnerId, permissions, status), `Pet` (type, level, xp, equippedItems, ownedItems), `Affirmation`, `Settings`. Продумай миграции Room с первого дня.

## Этапы
1. Каркас проекта, модули, DI, навигация, темы (Material You + тёмная), пустые экраны
2. Room + SQLCipher, модель данных, онбординг
3. `CyclePredictor` + тесты, главный экран с календарём и карточкой «сегодня»
4. Ежедневная запись (FAB), контент по фазам из JSON
5. Статистика: история циклов с полосками, сводки, графики
6. Гормоны, анализ фаз, вероятность беременности
7. Медитация и аффирмации
8. PIN/биометрия, Liquid Glass и другие стили — разбит на части:
   - 8а. PIN-код, биометрия, автоблокировка, скрытие в недавних
   - 8б. Стили (Liquid Glass, AMOLED, Пастель, Бумага, Неон), круговая палитра цветов интерфейса, главный экран на выбор (Кольцо с цветами, Луна, Орбита, Волна, Мозаика) с бóльшими отступами, экран PIN в стиле темы
   - 8в. Шрифт приложения в настройках: встроенные шрифты с кириллицей и свой файл .ttf/.otf
   - 8г. Кастомизатор главного экрана: порядок и видимость блоков, размер и вид плашек, цвет каждой плашки
9. Supabase: аккаунты, партнёрский режим, RLS
10. Питомец: выбор, анимации, кастомизация, прокачка, совместный режим
11. Виджеты и уведомления
12. PDF-отчёт для врача, экспорт/импорт
13. Полировка, accessibility, тесты, README

## Правила
- Не выдумывай медицинские утверждения: формулировки «возможно», «у многих», «типично». На экранах с вероятностью беременности, гормонами и прогнозами — дисклеймер «не является медицинской консультацией и методом контрацепции»
- Никакой аналитики и трекеров третьих сторон
- Код чистый, с понятными именами, без магических чисел (константы цикла — в одном месте)
- После каждого этапа: что сделано, что осталось, как проверить
